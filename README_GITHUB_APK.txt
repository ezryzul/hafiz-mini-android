HAFIZ MINI ANDROID V2 BM - BUILD APK AUTOMATIK
==============================================

Cara paling mudah:
1. Buat repository GitHub baru, contoh: hafiz-mini-android
2. Upload SEMUA fail/folder projek ini ke repository tersebut.
3. Pastikan branch utama bernama main.
4. Buka tab Actions.
5. Pilih workflow "Build Hafiz APK".
6. Tekan "Run workflow".
7. Tunggu build selesai.
8. Buka run yang berjaya.
9. Di bahagian Artifacts, download:
   Hafiz-Mini-Android-V2-BM
10. Extract artifact tersebut. Di dalamnya ada:
   app-debug.apk

APK debug itu boleh dipasang terus pada Android selepas membenarkan
"Install unknown apps" untuk browser/file manager yang digunakan.

Nota keselamatan:
- Tiada API key atau password Lovely Accounts disimpan dalam aplikasi.
- App ini hanya launcher/quick action untuk Hafiz dalam ChatGPT.
